# JavaScript 学习进度

最后更新：2026-08-18

## 已确认掌握

- 变量：`let`、`const` 的基本用法。
- 基本数据类型：字符串、数字、布尔值。
- 常用运算符与条件判断：比较运算符、`if / else if`；了解 `==` 与 `===` 的基本区别。
- 普通 `for` 循环：`index`、`index++`、数组下标和 `.length`。
- 函数：形参、实参、`return` 和模板字符串。
- 数组基础：用下标读取元素；理解下标从 `0` 开始、长度从 `1` 计数。
- 数组方法：能使用 `push()` 在数组末尾添加一项，并在 Astro 前置脚本区通过 Node.js 终端观察结果。
- 数组方法：理解 `pop()` 会移除并返回数组最后一项。
- 数组方法：能使用 `includes()` 判断数组是否包含某项，理解其返回 `true` 或 `false` 且不修改原数组。
- 对象基础：用点语法读取和修改属性，例如 `post.title`、`post.views`。
- 对象进阶：理解嵌套对象，能用连续点语法读取内层属性，例如 `post.author.name`。
- 函数语法：能使用箭头函数 `=>` 定义带参数和 `return` 的函数；理解 `title: string` 这种写法是在给参数标注类型，能避免隐式 `any`。
- 数组方法：理解 `map()` 会把数组每一项转换后返回新数组。
- 数组方法：理解 `filter()` 会按条件筛选数组并返回新数组。
- 数组方法：理解 `find()` 会返回第一个符合条件的元素，找不到时返回 `undefined`。
- 数组方法：理解 `forEach()` 会逐项执行回调，但不返回新数组。
- 对象方法：理解 `Object.keys()` 会把对象的键名变成数组。
- 对象方法：理解 `Object.values()` 会把对象的值变成数组。
- 对象方法：理解 `Object.entries()` 只把当前层对象转换为“键名、值”配对的二维数组。
- 字符串方法：理解 `trim()` 会返回去除字符串首尾空白后的新字符串，且不修改原字符串。
- 字符串方法：理解 `split()` 会按分隔符把字符串转换为数组；能结合 `map()` 和 `trim()` 清理博客标签中的空格。
- 字符串方法：理解 `toLowerCase()` 会返回全部转为小写的新字符串，可统一标签或用户输入的大小写，且不修改原字符串。
- 模块：能用 `export const` 从 `.ts` 文件命名导出数据，并用 `import { 名称 } from '路径'` 在 Astro 组件中导入使用；了解 `.astro` 组件可被默认导入。
- Astro 模板：理解 `{变量}` 可在标签文字或属性中读取并显示 JavaScript 值；知道这不是普通 `.ts` 文件语法。
- DOM：能在页面的 `<script>` 中使用 `document.querySelector()` 选择首个匹配的元素，并在浏览器控制台检查结果。
- DOM 事件：能使用 `addEventListener('click', ...)` 在点击元素后执行指定代码。
- DOM 内容：了解 `textContent`、`innerText` 与 `innerHTML` 的读取和写入差异；知道普通文字优先使用 `textContent`，避免把不可信内容写入 `innerHTML`。
- DOM 表单：能通过输入框的 `.value` 读取用户当前输入的内容，并在点击按钮后输出到浏览器控制台。
- TypeScript：能用 `as HTMLInputElement` 为已确认的输入框补充具体元素类型，理解它只影响类型检查而不转换运行时值。
- 事件回调：理解 `addEventListener('click', dl)` 传入函数以便点击时执行；`dl()` 则会立刻调用函数。
- DOM 交互：能在按钮点击后读取输入框内容，并用 `textContent` 更新首页标题；能通过 `if (pageTitle)` 处理元素可能不存在的情况。
- 输入校验：能在提交前用 `trim()` 清理输入，并用 `.length > 0` 阻止空内容覆盖首页标题。
- 交互反馈：能为 `if / else` 的不同分支提供对应提示，例如在输入为空时通过 `alert()` 告知用户。
