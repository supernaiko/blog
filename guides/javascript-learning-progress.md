# JavaScript 学习进度

最后更新：2026-08-16

## 已确认掌握

- 变量：`let`、`const` 的基本用法。
- 基本数据类型：字符串、数字、布尔值。
- 常用运算符与条件判断：比较运算符、`if / else if`；了解 `==` 与 `===` 的基本区别。
- 普通 `for` 循环：`index`、`index++`、数组下标和 `.length`。
- 函数：形参、实参、`return` 和模板字符串。
- 数组基础：用下标读取元素；理解下标从 `0` 开始、长度从 `1` 计数。
- 数组方法：能使用 `push()` 在数组末尾添加一项，并在 Astro 前置脚本区通过 Node.js 终端观察结果。
- 数组方法：理解 `pop()` 会移除并返回数组最后一项。
- 数组方法：能使用 `includes()` 判断数组是否包含某项，理解其返回 `true` 或 `false` 且不修改原数组。
- 对象基础：用点语法读取和修改属性，例如 `post.title`、`post.views`。
- 函数语法：能使用箭头函数 `=>` 定义带参数和 `return` 的函数；理解 `title: string` 这种写法是在给参数标注类型，能避免隐式 `any`。
- 数组方法：理解 `map()` 会把数组每一项转换后返回新数组。
- 数组方法：理解 `filter()` 会按条件筛选数组并返回新数组。
- 数组方法：理解 `find()` 会返回第一个符合条件的元素，找不到时返回 `undefined`。
- 数组方法：理解 `forEach()` 会逐项执行回调，但不返回新数组。
- 对象方法：理解 `Object.keys()` 会把对象的键名变成数组。
- 对象方法：理解 `Object.values()` 会把对象的值变成数组。
